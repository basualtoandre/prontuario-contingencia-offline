# prontuario-contingencia-offline

Sistema de contingência médica para uso local em HTML/JS para situações extremas de queda de rede hospitalar ou prontuário eletrônico a fim de manter registros simples em PDF e com design simples de fácil entendimento para acesso intuitivo.


COPIE O ARQUIVO PEP OFF NA ÁREA DE TRABALHO DO COMPUTADOR.
ABRA O ARQUIVO, UMA JANELA DE "LOGIN" DEVE APARECER NO PRIMEIRO USO - CASO NÃO APAREÇA O LOGIN VERIFIQUE O NOME DO MÉDICO QUE APARECE NA ABA ESQUERDA. CASO NÃO SEJA O SEU NOME VÁ EM HISTÓRICO GERAL LOCAL E CLIQUE EM LIMPAR TUDO.

FAÇA "LOGIN".
INSIRA O NOME COMPLETO DO MÉDICO QUE ESTARÁ ASSINANDO OS DOCUMENTOS E O RESPECTIVO CRM(UF).

DURANTE O USO INSIRA OS DADOS DOS PACIENTES QUE SERÃO ATENDIDOS DE FORMA OFFLINE. SEMPRE QUE TERMINAR EM UMA JANELA EMITA O PDF. O ARQUIVO NÃO SALVA HISTÓRICOS, EXCETO LOGS DE USO QUE PODEM SER LIMPOS AO FINAL - OS ARQUIVOS GERADOS EM PDF FICARÃO SALVOS NA PASTA DE DOWNLOAD DO SEU COMPUTADOR ONDE PODERÃO SER AGRUPADOS POSTERIORMENTE DE FORMA MANUAL PARA AUDITAR OU MESMO PARA MANTER UM REGISTRO PARA SEREM INSERIDOS NO PRONTUÁRIO DO HOSPITAL EM CASO DE QUEDA DE SISTEMA.

ATENÇÃO: ESTE É UM SIMPLES SISTEMA OFFLINE APENAS PARA USO EM SITUAÇÕES DE QUEDA GERAL DE REDE, SISTEMA, PROBLEMAS EM BANCOS DE DADOS E QUEDA DE PRONTUÁRIOS ELETRÔNICOS, A FIM DE FACILITAR PRESCRIÇÕES E EVOLUÇÕES COM RECEITA TAMBÉM. ELE NÃO SALVA HISTÓRICOS, SERVE APENAS PARA AGILIZAR DOCUMENTOS E CRIAR DOCUMENTOS EM PDF DOS ATENDIMENTOS REALIZADOS AO INVÉS DE FAZER O MÉDICO ABRIR MÚLTIPLAS JANELAS DO WORD OU OUTRO EDITOR DE TEXTO A FIM DE SER DIRETO NA APLICAÇÃO, OU EVITAR DOCUMENTAÇÃO MANUAL EM LUGARES QUE POSSUEM COMPUTADORES E IMPRESSORAS DISPONÍVEIS E CARECEM DE SISTEMAS DE PRONTUÁRIO ELETRÔNICO.
